# dsh-request-flight-recorder v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver v0.2 with process health, advanced retained-record queries, deterministic content-free diffs, an optional official `/flight` command, and official npm/GitHub bundle distribution documentation.

**Architecture:** Keep capture and diagnostics in the existing recorder service. Add pure query/diff/format modules, track health independently from bounded retention, and mount the human command through Cordis optional `commands` injection so the core stays active in minimal profiles.

**Tech Stack:** Node.js 22.19+, TypeScript 6, ESM, pnpm 11, Vitest 4, tsdown, Cordis 4.0.1, DeepSeek Harness 0.1.0-rc.6.

---

Commit, push, repository creation, Topic mutation, npm publication, and release steps are intentionally excluded because they require separate explicit authorization.

Add:

```ts
export interface FlightRecorderHealth {
  readonly captured: number
  readonly completed: number
  readonly active: number
  readonly retained: number
  readonly evicted: number
  readonly correlationMisses: number
  readonly projectionFailures: number
}
```

In the service, keep monotonic numeric counters and:

```ts
private activeIds = new Set<RequestAttemptId>()
```

Rules:

- Increment `correlationMisses` only after confirming `isAgentLoopRequest(options)`.
- A marked request with missing Signal counts as one miss.
- Every correlation mismatch counts once before delegating.
- Increment `projectionFailures` in both existing capture-failure catches.
- After store insertion, increment `captured`, add the id to `activeIds`, and increment `evicted` when insertion returns a record.
- On the first terminal outcome, delete from `activeIds`; only successful deletion increments `completed`.
- `health()` creates and freezes a fresh object using `store.size` and `activeIds.size`.
- The disposer resets every counter, clears the set, and keeps existing record cleanup.

```ts
diff(fromId: RequestAttemptId, toId: RequestAttemptId): FlightDiffResult {
  const from = this.store.get(fromId)
  const to = this.store.get(toId)
  const missing = [from === undefined ? fromId : undefined, to === undefined ? toId : undefined]
    .filter((id): id is RequestAttemptId => id !== undefined)
  if (missing.length > 0) return deepFreeze({ kind: 'missing', ids: missing })
  return deepFreeze({ kind: 'ok', diff: diffFlightRecords(from, to) })
}
```
